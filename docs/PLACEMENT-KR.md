# RepoRun 1.0.1 버튼 배치 규칙

[English](PLACEMENT.md) · [README](../README-KR.md)

## 기본 배치와 폴백

우측 About 영역의 맨 아래에 아이콘·실행 조건·짧은 부연문구가 있는 버튼 하나를 배치합니다. Watch/Fork/Star 및 Activities/Delta 등이 있는 헤더 액션 영역에는 넣지 않습니다. 적절한 About 영역을 찾을 수 없으면 우측 하단에 44 × 44 CSS 픽셀의 아이콘 전용 버튼 하나를 배치합니다. 화면 가장자리 간격은 기본 16px이며 safe-area inset을 고려합니다.

`src/content/placement.js`에서 배치 기준을 관리합니다. BorderGrid-cell 구조, About 전용 test marker, section 구조를 지원합니다. About과 Releases를 함께 포함하는 불명확한 래퍼의 맨 아래를 임의로 사용하지 않습니다. 별도 설명이 비어 있어도 About 블록을 식별할 수 있으면 배치합니다.

우측 사이드바는 화면에 렌더링되어야 하며 hidden/inert/aria-hidden 조상 아래에 있으면 제외합니다. 너비는 180px 이상, 화면 절반 이하이며, 좌측 시작점이 화면 너비의 45% 이후여야 합니다. 본문 아래로 쌓이는 레이아웃은 오른쪽 사이드바로 취급하지 않습니다. 스크롤로 About이 화면 밖으로 나갔다는 이유만으로 버튼을 중복 표시하지 않습니다.

## 이동과 접근성

리사이즈·사이드바 표시/숨김·DOM 교체 시 기존 버튼 노드를 이동하며 이벤트 리스너를 중복 등록하지 않습니다. GitHub가 캐시한 HTML에 오래된 호스트 복사본이 포함되어 있으면 제거합니다. ResizeObserver와 관련 DOM 변경·화면 크기·GitHub 내부 이동 이벤트로 재배치하며 상시 폴링이나 API 조회는 없습니다.

사이드바가 뒤늦게 나타나면 플로팅 버튼을 About으로 되돌립니다. 비저장소 페이지로 이동하면 버튼과 패널을 제거합니다. 키보드 접근명·포커스 표시·툴팁·패널 열림 상태를 제공하며, 플로팅 버튼으로 패널을 열면 배경 버튼은 잠시 숨기고 닫을 때 복원합니다. 다른 컨트롤로 옮긴 포커스를 임의로 빼앗지 않습니다.

## 검증 한계

GitHub DOM은 고정된 확장용 공개 인터페이스가 아닙니다. 인식되지 않는 실험적 레이아웃에서는 플로팅 버튼 및 확장 팝업으로 접근합니다. 모든 향후 GitHub 화면에 대해 사이드바 배치를 보장하지 않습니다. API·토큰·분석기 코드는 이번 변경 범위 밖입니다.

`npm run package` 후 Playwright·Chromium이 있는 환경에서 `python tests/placement_qa.py`로 검증합니다. 실제 Chromium DOM·레이아웃을 사용하지만 Chrome API와 GitHub 데이터는 모의이며, 제공 스크린샷은 실계정 GitHub 검증 자료가 아닙니다.
