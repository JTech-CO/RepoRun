설치 ZIP을 제출하고 소스 ZIP은 제출하지 마세요. `public/privacy-policy.html`을 CSS·아이콘과 함께 실제 HTTPS 경로에 호스팅해야 합니다. 로컬 파일 경로를 방침 URL로 등록하면 안 됩니다. 개발자 계정, 스토어 아이콘, 문의 경로와 실제 설치 화면은 별도 준비가 필요합니다. 포함된 스크린샷은 오프라인 모의 저장소이며 실제 GitHub 연동 증거가 아닙니다.

데이터 사용 설문은 현재 스토어 정의와 실제 동작을 대조하세요. 개발자 서버가 없더라도 토큰·저장소 정보·명령·경로를 처리합니다. 무조건 모든 항목을 '수집하지 않음'으로 체크하지 마세요. 심사 통과나 상표 사용 가능성을 보증하지 않습니다.
