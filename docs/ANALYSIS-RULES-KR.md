# 분석 규칙과 한계

[English](ANALYSIS-RULES.md) · [README](../README-KR.md)

**명시됨**은 해당 디렉터리의 파일 선언이나 존재를 확인했다는 뜻입니다. 실제 필수 조건·설치 상태·정확성·충분성을 보증하지 않습니다. **추정됨**은 현재 잠금 파일명에 따른 패키지 관리자 같은 제한된 단서입니다. **확인되지 않음**은 근거 부족·미지원·조회 불가이며, 필요 없다는 뜻이 아닙니다.

| 근거 | 처리 | 하지 않는 판단 |
| --- | --- | --- |
| engines·Volta·devEngines·버전 파일 | 각각의 선언과 원문 위치 | 버전 범위 교집합·설치 상태·호환성 확정 |
| packageManager·잠금 파일명 | 명시와 추정 구분, 충돌 주의 | 잠금 본문·의존성 전체 해석 |
| scripts | 실제 명령 표시, 일부 설치 훅 경고 | 실행·안전성 승인·설치 순서 생성 |
| 환경변수 예제 | 이름·줄 번호만 추출 | 값 표시·필수 여부 확정 |
| Dockerfile | 단일 줄 FROM 이미지 선언 | ARG·여러 줄 문법·Docker 필수 판정 |
| Compose | 파일 존재 | 서비스·프로필·변수·override 해석 |
| README | 셸 코드 블록에서 명령 일부 | 완전한 설치법·여러 줄 실행 문맥 |
| index.html·프레임워크·설정 파일 | 엔트리·의존성·파일 존재 | 정적 호스팅·오프라인·안전성 보증 |

본문 허용 목록은 package.json, 버전 파일, 환경변수 예제, README 변형, Dockerfile, Compose 변형, vercel.json, manifest.json입니다. 일부 본문은 현재 의미 해석 없이 파일 존재만 반영합니다. 잠금 파일·동적 JS/TS 설정·index.html·pnpm-workspace.yaml 등은 존재만 확인합니다. 근거 탭에서 실제로 읽은 항목을 구분합니다. 실제 `.env`·`.env.local`·`.npmrc`·잠금 본문·일반 소스 코드는 읽지 않습니다.

기본 브랜치, 경로 240자·5단계 이내의 한 디렉터리만 지원합니다. 상위 설정 상속·모노레포 자동 확장을 하지 않습니다. 비재귀 트리는 디렉터리별 최대 10,000개 항목이며 잘림을 알립니다. 본문 최대 14회 시도, 파일당 128 KiB, 요청별 15초 제한입니다. 전체 분석은 각 요청 전에 180초 예산을 확인하므로 이미 시작한 요청은 최대 15초 추가될 수 있습니다. API JSON 응답은 일반 2 MB, blob 220,000바이트 상한입니다. 동시 서로 다른 분석은 최대 3개이며 같은 범위 요청은 합칩니다.

스크립트 40개, 환경변수 이름 100개, README 예시 6개, .tool-versions Node 항목 30개, Docker FROM 20개가 표시 상한입니다. devEngines 배열은 범주별 20개, 워크스페이스 패턴은 12개까지 표시합니다. 표시 문자열은 길이 제한이 있으므로 전체 내용은 근거 원문을 확인합니다.

보고서는 세션에서 5분 동안 최신으로 취급하고 최대 8개·직렬화 UTF-8 150만 바이트로 제한합니다. 너무 큰 보고서는 캐시에 남지 않을 수 있습니다. 토큰 변경은 진행 중 요청 취소·캐시 비우기·인증 세대 변경을 수행합니다. 캐시만 비워도 기존 응답의 재저장을 막도록 세대를 변경하며 토큰은 유지합니다.

명령 복사는 안전성 인증이 아닙니다. 가림은 알려진 패턴에 대한 보조 조치일 뿐 모든 민감정보를 잡아내지 못합니다. 환경변수 예제 값은 결과에 남기지 않지만 다른 스크립트·README 문맥에는 민감정보가 있을 수 있습니다. 내보내기 전후 검토해야 합니다. 1.0.1은 정적 배포 호환성을 확정하지 않습니다.
